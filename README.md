# TianXiaYingXiongSha
类似于三国杀的多人卡牌对战游戏，但是接入AI，可以由玩家自定义英雄卡牌，由AI根据定制分配技能和特殊效果卡牌，进行对局，天下英雄，皆可入局。A multiplayer card battle game similar to 'Three Kingdoms Kill,' but with AI integration. Players can customize hero cards, and the AI assigns skills and special effect cards based on the customization for matches. Heroes from all over the world can join the game.
